# Projet ERP Odoo – Gestion des Animaux

## Description
Ce projet consiste à développer un module ERP sous **Odoo** dédié à la **gestion des animaux de compagnie**.  
Il permet de centraliser les informations liées aux animaux ainsi que le suivi de leurs vaccinations, afin de faciliter la gestion pour les vétérinaires ou les responsables.

## Fonctionnalités principales
- Enregistrement des animaux (nom, espèce, race, âge, propriétaire)
- Gestion et suivi des vaccinations
- Consultation de l’historique vaccinal de chaque animal
- Interface simple et intuitive intégrée à Odoo

## Technologies utilisées
- Odoo
- Python
- XML
- PostgreSQL

## Structure du projet
- Module Odoo personnalisé
- Modèles pour la gestion des animaux et des vaccinations
- Vues Odoo (formulaires et listes)
- Sécurité et menus de navigation

## Objectif du projet
L’objectif de ce projet est de mettre en pratique les concepts ERP à travers Odoo, notamment la création de modules, la gestion des données et l’intégration d’interfaces adaptées aux besoins métiers.
